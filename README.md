# Production App Builder AI

An AI engineering system for planning and building production applications from idea to deployment.

## Purpose

Guide developers through:

- Product planning
- Architecture
- Frontend
- Backend
- Database design
- Authentication
- Security
- Testing
- Deployment
- Legal protection

## Workflow

Idea → Requirements → Architecture → Build → Test → Secure → Deploy → Monitor

## Skills

Coming modules:

- Product planner
- Full-stack architect
- Security reviewer
- Legal compliance reviewer
- Deployment engineer

## Usage

Provide:

- Application idea
- Target users
- Required features
- Preferred technologies

The AI creates an implementation plan and selects the required engineering skills.
